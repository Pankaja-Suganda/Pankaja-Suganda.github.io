## Overview

ArgParser is a lightweight C++ library designed to streamline command-line argument parsing. It supports various data types, including boolean, integer, double, and string, allowing developers to effortlessly integrate command-line argument parsing into their applications.

## Key Features

- **Multi-Type Support**: Handles boolean, integer, double, and string types for versatile argument parsing.
- **Ease of Integration**: Simple API design facilitates quick integration into existing C++ projects.
- **Lightweight**: Minimal dependencies ensure that the library remains lightweight and efficient.
- **Open Source**: Available under the MIT License, encouraging community contributions and usage.
