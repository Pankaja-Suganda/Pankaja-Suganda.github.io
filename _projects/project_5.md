## Overview

The **MPU Simulation** project is a modular and extensible simulator built to support multiple microcontroller platforms. It emulates basic behaviors of microcontrollers such as register operations, memory management, and instruction handling. The goal is to provide a lightweight yet flexible environment for testing and educational purposes.

Supported platforms include:
- PIC

The project structure is cleanly organized into components such as MPU core logic, interrupts, memory, and utilities, making it easy to extend and maintain.

## Key Features

- **Modular Design:** Separated logic for MPU core, interrupts, memory, registers, and utilities.
- **Cross-Platform Development:** Designed for extensibility and adaptability across various embedded platforms.
- **Testability:** Allows isolated testing of modules like instruction sets and memory handling.
- **Educational Use:** Great for learning how microcontroller internals work.
